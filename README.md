# NOVA OS

Site oficial de download do NOVA OS 1.1.0.

- Site no ar: https://mattmierzwa.github.io/Nova-OS/
- Repositorio: https://github.com/MattMierzwa/Nova-OS

## Downloads

Os executaveis nao ficam neste repositorio (sao grandes demais). Estao anexados
a Release v1.1.0:

- https://github.com/MattMierzwa/Nova-OS/releases/latest/download/NOVA.OS.exe
- https://github.com/MattMierzwa/Nova-OS/releases/latest/download/NOVA.OS.Setup.exe

Os hashes SHA256 estao em `downloads/SHA256SUMS.txt`.

## Como publicar o site

GitHub Pages: Settings > Pages > Deploy from a branch > main / (root).

## Abrir localmente

Abra `index.html` no navegador. Quando aberto via file://, os botoes apontam
para os arquivos em `downloads/`. Quando publicado, apontam para a Release.
